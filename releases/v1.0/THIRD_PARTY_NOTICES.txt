Third-party components
=====================

vendor/concept-to-code/schemas/spec.schema.json
-----------------------------------------------
Registered in scripts/vendored_resources.py:VENDORED_RESOURCES (the sole authoritative declaration, chainlink #55 round 3) and read via vendored_resource_path() by scripts/select_pilot_cluster.py to validate concept specs during pilot-cluster ranking. The only vendor/ file any scripts/*.py actually needs at runtime -- everything else under vendor/ is copied-not-imported logic or prose reference. #57 replaced vendored_resource_path()'s own Path(__file__)-relative body with scripts/resources.py, which uses importlib.resources from a zipapp, so a distributed binary resolves this asset outside a ligature-workspace checkout. Call sites did not change, only that one function's body.
